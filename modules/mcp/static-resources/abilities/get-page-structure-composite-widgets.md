Composite widgets: an instance root has `widget: { id, version }`, and each of its atoms has `part` (and `slot: true` when it takes children). Update parts' settings and styles with `elementor/manage-elements`; parts can't be added, moved or deleted, and only a slot takes new children. A root with `widget.unavailable: "pro_required"` is a saved site widget hidden because the site has no Elementor Pro license; its content isn't returned.
