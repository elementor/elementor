Reads the Elementor System Info reports: server environment (`server`: PHP, MySQL, memory limits, write permissions), WordPress settings (`wordpress`), the active theme (`theme`), the current user (`user`), and active plugins (`plugins`, plus `mu_plugins` and `network_plugins` when present), and which plugins declare compatibility with Elementor (`elementor_compatibility`, `elementor-pro_compatibility`). Use ONLY when the user asks about their site environment or you are troubleshooting a problem (e.g. "why is my site slow", "which PHP version do I have", "is my uploads folder writable"). Do NOT call it as a default discovery step.

Pass `reports` with the report names you need (for example `["server", "wordpress"]`) to keep the response small. If none of the names exist, the error lists the available report names. Each report has `fields` with `name`, `label` and `value`. A field with `warning: true` is a detected problem, and its `recommendation` says how to fix it: trust them and relay them to the user. A `recommendation` without `warning: true` is general advice, not a problem. The `server` report also checks the connection to the Elementor library, which can take a few seconds when it is unreachable.

This tool is read-only. The report contains site details such as URLs and the admin email: share only what the user asked for. Requires administrator permission.
