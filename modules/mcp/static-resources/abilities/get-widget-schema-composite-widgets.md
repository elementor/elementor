Composite widgets: pass a widget id (`<namespace>/<name>`, e.g. `elementor/icon-button`, from the `composite_widgets` list of `elementor/list-widget-schemas`) to get `{ id, title, source, version, archived, insertable, parts, fields, allowed_part_types, usage }`. `parts` maps each part name to its element `type` (and `slot: true` for parts that take children); configure a part in `build-composition` under `<configuration-id>.<part>` with that element type's schema. `fields` lists the widget's main settings, each with its `target` part and prop and the prop's plain `schema`. `insertable` is false for archived widgets and for `site/` widgets without an active Elementor Pro license.
