Lists the Elementor experiments and features the site admin can switch on or off in WP Admin → Elementor → Settings → Features, and reports whether the Atomic Editor (V4) is on. Use when the user asks which experiments exist, whether a feature is on, or before changing one with `manage-experiments`. Each item has `state` (the saved choice: `default`, `active` or `inactive`) and `active` (whether it is effectively on right now); trust `active` to answer "is it on?". `dependencies` lists experiments that must be active first, and `deactivation_warning`, when present, describes what turning it off does. Requires administrator permission.
