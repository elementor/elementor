Reads or assigns the WooCommerce store pages: cart, checkout, my_account, terms, shop, and purchase_summary (the Elementor thank-you page). These are site-wide store settings, the same as WooCommerce → Settings → Advanced → Page setup and Site Settings → WooCommerce Pages. "get" returns the current page for each. "update" sets the pages passed in "pages" (published page IDs) and returns the previous and current ID of each, so keep them to revert. Always ask the user before calling "update", naming each page you will assign. Cart, checkout, my_account and purchase_summary pages must be built with Elementor; a warning is returned when they are not. All pages are validated first: if any is invalid, nothing is changed.
