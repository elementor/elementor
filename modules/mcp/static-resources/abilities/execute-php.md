Runs PHP on the server with full WordPress loaded. This is not sandboxed. Pass code without `<?php` tags. Use `return` to supply a value in `return_value`; `echo` and print output appear in `output`. Execution stops after 30 seconds (Php_Executor::MAX_EXECUTION_TIME_SECONDS). Nothing persists between calls. Changes are real and immediate on the site. Prefer read-file and list-directory for read-only inspection. Requires administrator permission and Super Admin enabled.
