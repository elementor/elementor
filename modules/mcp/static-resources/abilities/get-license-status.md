Reads the site's Elementor Pro license status and plan. Use when the user asks which plan or license they have, or before suggesting or using a Pro-only feature. Returns `status`: `active` (valid Pro license), `expired` (license ran out), `inactive` (Pro is installed but has no valid license) or `pro_not_installed` (only free Elementor). `tier` is the plan id (`free`, `essential`, `essential-oct2023`, `advanced`, `expert`, `agency`) and is always `free` unless `status` is `active`. `label` is the plan name to show the user. Does not return the license key or account details. Requires administrator permission.
