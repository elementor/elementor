# Product / UX

Judge against the ticket AC and existing product behavior.
- Each AC met; behavior beyond AC flagged as scope creep.
- V3 parity where the ticket claims it; intentional differences stated.
- States: empty, loading, error, disabled, Pro-locked (promotion shown correctly, no dead-end click).
- Copy: strings, i18n, tone consistent with neighbors; terminology matches the product.
- Defaults sensible; discoverability; consistency with similar controls/widgets.
- Migration/upgrade effect on existing sites and content.

Accessibility standards belong to `accessibility`; code quality to `quality`. Lens name `product`. Follow common.md.
