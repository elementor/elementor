# QA

Complements `01-scope` (which owns test bloat). This lens owns risk coverage.
- Risky paths covered: error/empty/invalid input, permissions, license on/off/expired, Pro inactive, Core-only, old/new version combos, import/export round trip, undo/redo, responsive/RTL, multisite where relevant.
- Each ticket edge case from the look-for list has a test or a reasoned gap.
- Test quality: asserts behavior not implementation, deterministic, no blind waits, correct level (unit vs integration vs Playwright), snapshots justified.
- Regression risk: other consumers of changed code, shared fixtures, snapshot updates that hide behavior changes.
- Manual verification gaps worth running.

Lens name `qa`. Follow common.md.
